# 架构与权限

## 采集与整理

Swift/AppKit/SwiftUI 应用提供全局开始/结束快捷键、语音采集、Finder 选项读取及可编辑侧栏。Chrome 扩展采集网页选区、链接与图片，通过 Native Messaging 和用户目录中的本地 socket 与应用通信。

语音片段、词时间、选择手势起止和素材事件使用共同时间线关联。一次拖选内的字符快照归并为最终选择，同时保留原始证据。结束表达后使用完整录音复核，再交给 Codex CLI 整理为任务正文。自由编辑后的正文作为交付真值，后台整理不得覆盖同时发生的编辑。

## 投递

只读对话目录提供标题、项目路径和完整 ID；标题用于展示，完整 ID 用于绑定。填写前后通过 Codex 原生复制深层链接命令核对当前对话，拒绝标题相同但 ID 不同的目标。

准备阶段只保留正文明确引用的素材。辅助功能路径核对窗口、唯一输入控件、焦点、已有草稿和 UTF-8 正文回读后，发送一次原生 ⌘Return。只读接收检查核对新的用户消息内容；结果未知时停止，避免重复提交。

## 本地身份与存储

`local.contextcapture.prototype` Bundle ID、`ContextCapture` 可执行文件名和 `ContextCapturePrototype` 数据目录为兼容标识，不随应用显示名称变化。

本地构建使用持久化的私有签名身份与证书固定的 designated requirement。缺少身份时构建失败，不静默回退到临时签名。`tools/local_signing.py` 包含身份建立与校验逻辑；信任配置和钥匙串访问需要用户根据本机系统提示完成。仓库不携带可直接复用的身份配置。

辅助功能用于跨应用读取和人主动触发的填写/提交；麦克风用于本次表达；Finder 自动化用于选中文件读取。权限由用户在 macOS 中授予，应用不修改系统隐私数据库。

扩展公开密钥用于固定扩展 ID，不是私钥。Native Messaging 宿主名与用户目录中的桥接路径保持稳定。扩展安装和权限确认由用户完成。

## 发布边界

本地会话、原始音频、截图、个人验证报告、目标对话配置和签名材料属于本机运行数据，不纳入公开源码。公开测试使用合成正文、示例域名、临时文件和人工构造的对话 ID。
