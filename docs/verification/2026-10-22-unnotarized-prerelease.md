# 未公证预发布版本验证

用户明确选择将完整功能的未公证测试版放到 GitHub，由试用者自行决定是否在系统设置中允许打开。本轮使用独立的未公证模式，原有正式 Developer ID／公证／第二台 Mac 验收门槛保持不变。

## 产物

- 版本：0.2.0-trial.1，内部构建号 2，Apple Silicon／macOS 26+。
- 完整功能的 DMG、中文安装说明、SHA256SUMS 和公开状态 JSON。
- 所有内置 Mach-O 与外层应用使用 ad-hoc 签名封装；没有使用或分发个人证书、私钥和账号配置。
- `notarized=false`、`cleanMacAccepted=false`、正式 `publishReady=false`；独立 `unnotarizedTrialReady=true` 表示通过本机检查的未公证试用包。

## 已执行

- 73 核心 + 70 原生集成 + 17 浏览器 + 42 Python，共 202 项检查通过。
- 真正执行内层和外层签名封装，`codesign --verify --deep --strict` 通过。
- 签名时发现原先裸 Python 目录不应放在预留 Frameworks 位置，已将完整解释器移动至 Resources/Python；同步更新路径解析、打包器和搬迁检查。没有删除解释器组件或产品功能。
- 将已封装应用复制到含空格、中文、单引号的目录，内置运行时、70 项原生检查及辅助程序检查通过，整个应用包文件未被改写。
- 对确切交付的 DMG 进行只读挂载，挂载后再次核对严格签名、应用、Applications 快捷方式和“未经过 Apple 公证”说明，随后卸载。
- 对安装包内容扫描已知私有路径、原始测试对话／会话 UUID 和私钥、账号文件名，无残留。校验值文件与交付资产匹配。
- 本机现有应用、签名配置、目标对话与 Chrome 桥接内容哈希不变；主工作目录没有修改，也没有替换或重启现有应用。
- 独立审查没有发现新的阻断问题，最终仍以真实签名与检查结果为依据。
