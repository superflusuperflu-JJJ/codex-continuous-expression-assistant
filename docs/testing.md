# 检查与验证

运行 `zsh tools/check.sh`。

自动化检查包括：

- 核心关联：词时间、选择边界、连续拖选、指代、重复表达和语义来源。
- 编辑与选择：光标保持、中文输入法、手动改写保护、推荐选项和持久化。
- 桌面投递：完整 ID、同名对话、已有草稿保护、焦点核对、提交门控和接收正文匹配。
- 网页桥接：事件顺序、截止时间、重试、截图失败和新标签页恢复。
- 素材包装：只发送有用途的素材，编辑后删除的引用不得重新出现。
- 本地签名：拒绝无效身份、固定证书要求、不使用二进制 hash 绑定权限身份。

核心与原生检查使用可执行行为检查器，避免依赖本机缺失的 Swift Testing 运行库。Python 检查和浏览器 Node 测试不连接真实用户对话。测试 ID 是合成数据，不能用作发送目标。

真实麦克风、噪声、多显示器、网页兼容性、辅助功能授权和桌面接收需要独立人工试用；单元检查不替代这些验证。个人试用报告、原始内容与诊断文件保留在本地或私有开发归档，不在本仓库公开。
